    Tutorial de Uso: Ilha Delivery

    Este tutorial detalhado guia os usuários Clientes e Operadores através de todas as funcionalidades disponíveis no aplicativo Ilha Delivery, facilitando o processo de entrega de produtos para moradores da Ilha Primeira.

    1. Guia para Clientes

    1.1. Acesso Inicial e Cadastro

    1.1.1. Tela Inicial

    Ao abrir o aplicativo pela primeira vez, você verá: - O logo da Ilha Delivery - Dois botões: "Entrar como Cliente" e "Entrar como Operador"

    1.1.2. Cadastro de Novo Usuário

    Para criar uma conta:

    1. Na tela inicial, clique em "Entrar como Cliente"
    2. Na tela de login, clique em "Não tem conta? Cadastre-se"
    3. Preencha o formulário de cadastro com:
    4. Dados Pessoais:
      • Nome completo
      • CPF (será usado para identificação)
      • Telefone (para contato)
      • Senha (para acessar sua conta)
    5. Endereço Completo:
      • Rua
      • Número
      • Cidade
      • Estado
      • CEP
      • Ilha (importante para a entrega)
    6. Clique em "CADASTRAR"
    7. Após confirmação, você será direcionado para a tela de login

    IMPORTANTE: O endereço correto e completo é fundamental para garantir as entregas com precisão.

    1.1.3. Login

    Para acessar sua conta: 1. Na tela de login, digite seu CPF (apenas números) 2. Digite sua senha 3. Clique em "ENTRAR"

    1.2. Tela Principal (Home)

    A tela principal apresenta:

    • Cabeçalho de Boas-vindas: Uma saudação personalizada com seu nome
    • Endereço de Entrega: O endereço cadastrado para suas entregas
    • Mapa de Entrega: Visualização da localização aproximada do entregador e tempo estimado de chegada para pedidos em andamento
    • Últimos Pedidos: Lista com seus três pedidos mais recentes, exibindo:
    • Número do pedido
    • Origem (ex: IFOOD, AMAZON, Mercado Livre)
    • Status atual do pedido (com cores diferentes para cada status)
    • Data do pedido
    • Botão "Ver todos os pedidos": Para acesso ao histórico completo

    1.3. Navegação no Aplicativo

    O menu de navegação inferior contém: - Home: Retorna à tela principal - Pedidos: Lista completa de todos os seus pedidos - Pedido+: Criação de novos pedidos - Perfil: Configurações da conta e logout

    1.4. Criando um Novo Pedido

    Para solicitar a entrega de produtos:

    1. Navegue até a aba "Pedido+" (ícone de +)
    2. No formulário "Novo Pedido", preencha:
    3. Nome do produto: Descrição clara do item
    4. Quantidade: Número de unidades
    5. Link do produto: URL da página da compra online
    6. Descrição (opcional): Detalhes adicionais sobre o produto
    7. Origem da compra: Selecione entre iFood, Amazon, Mercado Livre ou Outro
    8. Preço do produto: Valor unitário em reais
    9. Clique em "Criar Pedido"
    10. Confirme a criação quando solicitado

    Após a criação, seu pedido receberá o status "Solicitado" (SOL) e aguardará cotação do operador.

    1.5. Acompanhando Seus Pedidos

    1.5.1. Lista de Pedidos

    1. Acesse a aba "Pedidos" (ícone de calendário)
    2. Veja a lista de todos os seus pedidos, ordenados do mais recente para o mais antigo
    3. Para cada pedido, você visualiza:
    4. Número do pedido
    5. Data do pedido
    6. Status atual
    7. Origem
    8. Quantidade de produtos
    9. Puxe a tela para baixo para atualizar a lista

    1.5.2. Detalhes do Pedido

    Para ver informações detalhadas: 1. Toque em qualquer pedido da lista 2. Na tela de detalhes, você encontrará: * Informações gerais: Número do pedido e status (com código de cores) * Detalhes: Origem, datas de criação, estimada e efetiva de entrega * Lista de produtos: Nome, quantidade, preço unitário, descrição e link * Resumo financeiro: Subtotal dos produtos, taxa de entrega, taxa de serviço e preço final

    1.5.3. Estados do Pedido

    Seu pedido passará pelos seguintes estados: - Solicitado (SOL): Pedido criado, aguardando cotação - Cotação Enviada (CE): Operador definiu preço e frete, aguardando sua aprovação - Pagamento Aprovado (PA): Você aceitou a cotação - Em Andamento (AND): Pedido está sendo processado ou está em rota - Entregue (ENT): Pedido já foi entregue - Cancelado (CAN): Pedido foi cancelado

    1.5.4. Aprovando uma Cotação

    Quando o status do pedido for "Cotação Enviada":

    1. Ao acessar os detalhes do pedido, você verá um resumo com:
    2. Subtotal dos produtos
    3. Taxa de entrega
    4. Taxa de serviço (se houver)
    5. Preço final
    6. Se concordar com os valores, clique no botão "Aceitar Cotação"
    7. Confirme a operação quando solicitado
    8. O status mudará para "Pagamento Aprovado" e o operador será notificado

    1.5.5. Atualizações em Tempo Real

    • O aplicativo atualiza automaticamente o status dos pedidos a cada 5-30 segundos
    • Você pode atualizar manualmente usando o botão "Atualizar Dados" na tela de detalhes

    1.6. Gerenciando sua Conta

    1.6.1. Perfil e Configurações

    Na aba "Perfil" (ícone de configurações), você pode: * Visualizar seus dados cadastrais * Fazer logout do aplicativo

    1.6.2. Logout

    Para sair do aplicativo com segurança: 1. Acesse a aba "Perfil" 2. Clique no botão "Sair" 3. Confirme a operação quando solicitado

    2. Guia para Operadores

    2.1. Acesso do Operador

    2.1.1. Login do Operador

    1. Na tela inicial do aplicativo, selecione "Entrar como Operador"
    2. Digite seu Turno (ex: manha, tarde ou noite)
    3. Digite sua Senha
    4. Clique em "Entrar"

    O sistema validará suas credenciais e, se corretas, você será direcionado para a tela principal de gerenciamento de pedidos.

    2.2. Gerenciamento de Pedidos

    2.2.1. Visualizando Pedidos

    A tela principal dos operadores apresenta:

    • Filtro de Status: No topo da tela, permite filtrar pedidos por status
    • Lista de Pedidos: Todos os pedidos conforme o filtro selecionado
    • Para cada pedido, você visualiza:
    • Número do pedido
    • Status (com código de cores)
    • Origem (ex: IFOOD, AMAZON)
    • Cliente associado
    • Data e hora de criação

    2.2.2. Filtrando Pedidos

    Para facilitar o gerenciamento, utilize o filtro por status: 1. Toque no seletor de filtro no topo da tela 2. Escolha entre as opções: * Todos: Visualiza todos os pedidos * Solicitado (SOL): Pedidos aguardando cotação * Cotação Enviada (CE): Cotações enviadas aguardando aprovação * Pagamento Aprovado (PA): Pedidos aprovados pelo cliente * Em Andamento (AND): Pedidos em processamento * Entregue (ENT): Pedidos já entregues * Cancelado (CAN): Pedidos cancelados

    A lista atualiza automaticamente a cada 5 segundos para mostrar novas solicitações.

    2.3. Detalhes do Pedido e Ações

    Ao selecionar um pedido da lista, você acessa a tela de detalhes onde pode:

    2.3.1. Visualizar Informações Completas

    • Informações do Pedido: Número, status, origem, datas
    • Dados do Cliente: Nome do cliente
    • Produtos: Lista detalhada com nome, quantidade, preço unitário, descrição e link

    2.3.2. Enviar Cotação (para pedidos com status "SOL")

    1. No campo "Preço final (produto + frete) em R$", digite o valor total da cotação
    2. No campo "Valor do frete", informe o valor específico do frete
    3. Opcionalmente, no campo "Data estimada entrega", informe a data prevista
    4. Clique em "Enviar Cotação"

    Esta ação mudará o status do pedido para "CE" (Cotação Enviada) e notificará o cliente para aprovação.

    2.3.3. Atualizar Status (para pedidos com cotação aprovada)

    Após o cliente aprovar a cotação (status "PA"):

    • Iniciar Processamento: Clique em "Atualizar para ANDAMENTO" quando iniciar o processamento do pedido
    • Cancelar Pedido: Se necessário, clique em "Atualizar para CANCELADO"

    2.3.4. Finalizar Entrega

    Quando o pedido for entregue ao cliente:

    1. Clique no botão "Finalizar Pedido (ENTREGUE)"
    2. O sistema registrará automaticamente a data e hora da conclusão
    3. O cliente será notificado sobre a entrega finalizada
    4. O status mudará para "ENT" (Entregue)

    2.4. Gerenciamento de Conta

    2.4.1. Perfil do Operador

    Para acessar seu perfil: 1. Toque na aba "OperadorPerfil" (ícone de usuário) 2. Visualize suas informações de operador

    2.4.2. Logout

    Para sair do aplicativo com segurança: 1. Acesse a aba "OperadorPerfil" 2. Clique no botão "Sair" 3. Confirme a operação quando solicitado

    2.5. Melhores Práticas para Operadores

    1. Cotações claras: Sempre detalhe corretamente os valores de produto e frete
    2. Atualizações frequentes: Mantenha os status dos pedidos sempre atualizados
    3. Comunicação: Use o campo de data estimada para informar expectativas realistas
    4. Verificação: Confirme os dados do pedido antes de finalizar a entrega
    5. Monitoramento: Verifique regularmente os pedidos com status "Solicitado" para não deixar clientes esperando
