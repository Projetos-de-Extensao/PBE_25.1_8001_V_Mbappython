# Modelagem

Na fase de elaboração do projeto Ilha Delivery, realizamos a modelagem do sistema para definir sua estrutura e comportamento. Esta seção contém documentos que detalham diferentes aspectos da arquitetura e design do sistema.

## Documentos de Modelagem

- **[Diagrama de Classes](diagrama_de_classes.md)**: Representa a estrutura estática do sistema, mostrando classes, atributos, métodos e relacionamentos entre objetos.

- **[Diagrama de Análise de Sistema (DAS)](das.md)**: Apresenta a arquitetura do sistema, incluindo componentes, interfaces e interações entre eles.

## Objetivo

O objetivo principal da modelagem é criar uma representação visual e técnica do sistema antes da implementação, facilitando:

- O entendimento do domínio do problema
- A comunicação entre os membros da equipe
- A identificação de padrões e componentes reutilizáveis
- A criação de uma base para a implementação

A modelagem seguiu princípios de engenharia de software e práticas recomendadas para sistemas web e móveis, garantindo que a arquitetura suporte os requisitos funcionais e não-funcionais estabelecidos na fase de iniciação.
